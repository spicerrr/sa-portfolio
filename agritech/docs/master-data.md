# 🗂 master data

## Что является справочником

Сорт, тип операции и единица измерения — справочные сущности. Участок — объект производственного домена с общим ID. Партия, складская приёмка и измерение качества — транзакционные факты; они не становятся master data из-за наличия идентификатора.

## Каноническая запись и ключ источника

```json
{"varietyId":"VAR-017","canonicalName":"Golden Delicious","status":"ACTIVE"}
```

| Источник | Ключ записи | Отображаемое название | Канонический ID |
|:---|:---|:---|:---|
| ERP | ERP-V-104 | Golden Delicious | VAR-017 |
| WMS | WMS-V-22 | Голден | VAR-017 |
| LEGACY | LEG-V-7 | ГОЛДЕН ДЕЛИШЕС | VAR-017 |

Ключ `(система, тип сущности, ID записи)` стабилен. Нормализованное название помогает найти кандидатов, но не подтверждает идентичность: два разных сорта могут иметь похожие названия. Опечатки и новые сокращения направляются ответственному MDM.

## Процесс сопоставления

1. Выгрузить ключ, исходное имя, систему и дату.
2. Удалить крайние пробелы, схлопнуть повторные пробелы, привести Unicode к NFKC и регистру для поиска кандидатов.
3. Проверить существующий утверждённый mapping.
4. Если mapping отсутствует, записать `UNRESOLVED`; не создавать сорт автоматически.
5. Ответственный сверяет дополнительные атрибуты, утверждает соответствие; изменение существующего mapping требует отдельного review и анализа зависимых фактов.
6. Передать канонические данные потребителям. Для v1 используется согласованная реплика без детализированного транспорта обновлений; версия реплики и время синхронизации фиксируются.

Деактивация запрещает новые регистрации; исторические ссылки сохраняются. Переименование не меняет `varietyId`. Переназначение ключа источника на другой сорт нельзя применять к истории без процедуры коррекции.

## Контроль качества

| Проверка | Реакция |
|:---|:---|
| Один исходный ключ направлен на разные ID | Остановить загрузку, создать задачу MDM |
| Канонический ID отсутствует | Остановить загрузку |
| Нет mapping | `UNRESOLVED`, регистрация не выполняется |
| Различаются только написания | Возможный кандидат; требуется утверждение |
| Неактивный сорт | История читается, новый факт отклоняется |

[CSV соответствий](../examples/source-mappings.csv), [исходные записи](../examples/source-records.csv) и [скрипт](../scripts/normalize.py) демонстрируют проверку утверждённых ID. Результат: две разрешённые записи и одна неразрешённая; скрипт не является системой MDM.

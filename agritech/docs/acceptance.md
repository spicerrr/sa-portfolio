## Проверка результата

По каждому тесту фиксируются версия контрактов, данные, ожидаемое и фактическое поведение, подтверждение из API/БД/журнала и дефект. Отдельно проверяется отсутствие лишних объектов: успешный ответ сам по себе не подтверждает идемпотентность.

Метрики внедрения требуют исходного замера: доля ручных сопоставлений, число неразрешённых ключей, доля партий без приёмки в проекции, задержка доставки. В кейсе эти показатели предложены для оценки, измеренный эффект не заявлен.

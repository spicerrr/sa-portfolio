# 👥 заинтересованные стороны

Процесс затрагивает производство, склад, учёт, справочники и отчётность. В таблице показано, какие решения принимает каждый участник и по каким признакам оценивает результат. Один человек может совмещать несколько ролей.

## Участники и их задачи

| ID / роль | Интерес и проблема | Данные / решения | Влияние и участие | Критерий результата |
|:---|:---|:---|:---|:---|
| SH-01 Руководитель производства | Сбор продолжается при недоступности склада; понятна полнота отчёта | Правила регистрации и обработки ошибок | Высокое; согласует процесс | Подтверждённый сбор не теряется и не вводится повторно |
| SH-02 Главный агроном | Сорт и площадь соответствуют посадкам | Смысл сорта, участок–сезон–сорт, плодоносящая площадь | Высокое; согласует агрономические данные | Урожайность считается по согласованной площади |
| SH-03 Оператор производственного учёта | Однократно ввести подтверждённый сбор и получить ID | Журнал сбора, дата, масса, документ источника | Среднее; интервью и проверка UC-02 | Понятен результат запроса после разрыва связи |
| SH-04 Ответственный за справочники | Устранить дубли без искажения истории | Единые записи, ключи источников, соответствия | Высокое по справочникам; выполняет UC-01 | Нет неоднозначных утверждённых ключей |
| SH-05 Кладовщик | Принять физический груз и сохранить собственное измерение | Масса приёмки, складской документ | Среднее; выполняет UC-03 | Разница весов видна, производственный факт не переписан |
| SH-06 Руководитель склада | Исключить двойную ожидаемую приёмку и необъяснимые расхождения | Правила полной приёмки, разбор расхождений | Высокое; согласует складскую часть | Повтор сообщения не порождает второй документ |
| SH-07 Экономист / учёт | Связать данные учёта с конкретными документами сбора и приёмки | Номенклатура, учётные документы, методика затрат | Высокое по учёту; консультирует | Сохраняется связь с первичным документом; затраты не смешаны с массой |
| SH-08 Логист | Сопоставлять перевозку с грузом | Рейс, транспортный документ | Консультирует по перевозкам | Рейс связан с грузом по документам перевозки |
| SH-09 Аналитик BI | Воспроизвести показатель и найти неполные связи | Формула, единица расчёта, контрольные суммы | Среднее; выполняет UC-04 / UC-05 | Итог раскрывается до исходных фактов |
| SH-10 Команда ЦТ / аналитик системы | Согласовать процесс, данные, контракты и ограничения | Спецификации и трассировка | Координация, без полномочий исправлять бизнес-факты | Изменение отражено во всех зависимых артефактах |
| SH-11 Разработка / сопровождение | Восстановить обмен и диагностировать сбой | Реализация, журнал, DLQ | Техническое решение и поддержка | Повторная доставка безопасна и прослеживаема |

## Конфликты требований

| Конфликт | Принятое решение | Кто согласует |
|:---|:---|:---|
| Производство хочет сразу подтвердить сбор; склад доступен не всегда | Регистрация завершается локально, склад получает событие позднее | SH-01, SH-06; FR-03, NFR-01 |
| Склад доверяет своим весам; производство — своим | Хранить два измерения, анализировать разницу без автоматического списания | SH-02, SH-06, SH-07; BR-03 |
| Пользователь хочет подобрать сорт по имени; ответственный за справочники требует подтверждения | Приведение имени к единому виду помогает найти кандидата, утверждение требует подтверждения владельца | SH-02, SH-04; BR-01 |
| Руководитель хочет итоговую урожайность; часть данных не связана | Показывать полноту отдельно и не выдавать неполную приёмку за потери | SH-01, SH-09; FR-05 |

## Полномочия на согласование

Матрица распределяет подготовку и утверждение решений. Право согласовать справочник отдельно от права зарегистрировать сбор.

| Решение | Кто утверждает | Кто готовит / выполняет | С кем сверяют | Кого уведомляют |
|:---|:---|:---|:---|:---|
| Связать локальный код с единым сортом | Главный агроном | Ответственный за справочники | Производственный учёт, экономист | BI, системный аналитик |
| Утвердить плодоносящую площадь | Главный агроном | Производственный учёт | BI | Руководитель производства |
| Подтвердить сбор | Руководитель производства | Оператор учёта | Главный агроном | Склад |
| Подтвердить приёмку | Руководитель склада | Кладовщик | Производственный учёт | Экономист, BI |
| Согласовать формулу урожайности | Главный агроном | Аналитик BI | Руководитель производства, экономист | Системный аналитик |
| Выпустить спецификацию обмена | Системный аналитик | Разработка | Производство, склад | BI |
| Вернуть сообщение из очереди ошибок | Сопровождение | Сопровождение | Аналитик; ответственный за справочники при ошибке кода | Владелец затронутого документа |

Роль оператора производства `production_operator` даёт право регистрации сбора; `mdm_reader` даёт чтение соответствий, но не право их утверждения. Кладовщик действует в WMS. Изменения справочников в первой версии согласуются в управляемом реестре и выпускаются по [регламенту версий](versioning.md).

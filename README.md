## «Смена»

Проект игровой функции для приложения DDX Fitness. Пользователь выполняет задания с инвентарём и оборудованием, получает результат и может перейти к записи на Smart Start — вводное занятие с тренером.

Проработаны связь экранов с состояниями сессии, сохранение и возобновление прохождения, потеря связи и повторные запросы. Продуктовые события позволяют проследить путь от начала игры до перехода к записи.

Спецификация готова. Доступ к репозиторию — по приглашению.

[**Открыть кейс →**](https://github.com/spicerrr/ddx-smena-sa)

## Движение партии

Оператор регистрирует сбор, кладовщик подтверждает приёмку, руководитель получает отчёт. Производство и склад используют разные коды и фиксируют собственные измерения массы.

Проработаны исходные источники и связи между документами, согласование сортов, регистрация партии и складское подтверждение. Например, повтор запроса после потери ответа возвращает прежний номер партии, а расхождение масс сохраняется для сверки.
